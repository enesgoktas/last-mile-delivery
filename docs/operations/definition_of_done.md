# Definition of Done by Wave

## All waves
- Code merged with review.
- Tests passing in CI.
- Docs updated.
- Rollout/rollback notes present.
- Recovery posture and backup/restore notes updated when operational assumptions change.

## Phase-specific
- Phase 1: CRUD/auth/tracking/manual dispatch functional.
- Phase 2: Optimization and re-optimization stable with telemetry.
- Phase 3: Mobile route + POD + offline sync functional.
- Phase 4: Integrations, webhooks, import, tracking UX complete.
- Phase 5: Dashboard and analytics complete with exports.
